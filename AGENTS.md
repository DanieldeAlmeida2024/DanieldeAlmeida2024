# AGENTS — perfil GitHub

Objetivo: apresentar projetos de forma correta a recrutadores e leitores técnicos.

- Não declarar projeto em produção ou certificado sem evidência verificável.
- Diferenciar repositórios próprios, forks e exercícios de curso.
- Não publicar credenciais, dados privados ou material de projetos confidenciais.
- Preservar links de perfil e certificados antes de atualizações.
- Escrever em português claro e priorizar resultados técnicos verificáveis.
